Which method should I use?

These are useful starting points. More than one method can work; check each method’s assumptions before using it.

Variables can be separated

y′=g(x)h(y)y'=g(x)h(y)y′=g(x)h(y)

Separate and integrate. Check constant solutions. →

First-order linear

y′+P(x)y=Q(x)y'+P(x)y=Q(x)y′+P(x)y=Q(x)

Normalize, then use an integrating factor. →

A differential form

M dx+N dy=0M\,dx+N\,dy=0Mdx+Ndy=0

Check whether the cross partials match. →

A ratio or a power of y

y′=F(y/x)y'=F(y/x)y′=F(y/x) or a Bernoulli equation

Change variables to reach a familiar form. →
