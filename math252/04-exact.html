MATH 252 / LESSON 04 / SECTIONS 2.4

Exact equations

Recognize a hidden total derivative and reconstruct its potential function.

Before you start: Partial derivatives and integration with one variable held constant.

UnderstandMethodExample 1Your turnAvoid this mistake

THE IDEA

Understand before calculating

The hidden function

Write the equation as M(x,y) dx+N(x,y) dy=0.M(x,y)\,dx+N(x,y)\,dy=0.M(x,y)dx+N(x,y)dy=0. It is exact when a function FFF satisfies Fx=MF_x=MFx​=M and Fy=NF_y=NFy​=N. Then dF=0dF=0dF=0, so solutions lie on F(x,y)=CF(x,y)=CF(x,y)=C.

Test before integrating

With continuous first partials on a simply connected region, the test is My=Nx.M_y=N_x.My​=Nx​. When you integrate MMM with respect to xxx, the constant can depend on yyy: write F=∫M dx+g(y)F=\int M\,dx+g(y)F=∫Mdx+g(y).

If the first test fails

Some equations become exact after multiplication by an integrating factor. If (My−Nx)/N(M_y-N_x)/N(My​−Nx​)/N is a function of xxx alone, use its integral in μ(x)=e∫(My−Nx)/N dx\mu(x)=e^{\int (M_y-N_x)/N\,dx}μ(x)=e∫(My​−Nx​)/Ndx. If (Nx−My)/M(N_x-M_y)/M(Nx​−My​)/M depends only on yyy, use μ(y)=e∫(Nx−My)/M dy\mu(y)=e^{\int (N_x-M_y)/M\,dy}μ(y)=e∫(Nx​−My​)/Mdy. These tests apply where the denominators are nonzero; check the multiplied equation again.

Your method checklist

  1. Identify M and N and compare the cross partials.
  2. Integrate M in x, adding g(y).
  3. Differentiate that result in y and match N to find g.
  4. Write F=C and use any initial condition.

WORKED EXAMPLE

Recover the hidden potential

Solve (2xy+3) dx+(x2+4y) dy=0(2xy+3)\,dx+(x^2+4y)\,dy=0(2xy+3)dx+(x2+4y)dy=0 through (0,1)(0,1)(0,1).

  1. 1

    Test exactness

    My=2x=NxM_y=2x=N_xMy​=2x=Nx​, so the equation is exact.

  2. 2

    Integrate M

    F=x2y+3x+g(y).F=x^2y+3x+g(y).F=x2y+3x+g(y). The term ggg is a function, not yet a numerical constant.

  3. 3

    Match the other partial

    Fy=x2+g′(y)=x2+4y.F_y=x^2+g'(y)=x^2+4y.Fy​=x2+g′(y)=x2+4y. Hence g′=4yg'=4yg′=4y and we can take g=2y2g=2y^2g=2y2.

  4. 4

    Apply the initial point

    At (0,1)(0,1)(0,1), F=2F=2F=2. An implicit answer is completely acceptable.

RESULTx2y+3x+2y2=2x^2y+3x+2y^2=2x2y+3x+2y2=2

Check the answer

Differentiating this level curve gives precisely the original differential form.

TRY IT YOURSELF

Your turn

Solve (2x+y) dx+(x+2y) dy=0(2x+y)\,dx+(x+2y)\,dy=0(2x+y)dx+(x+2y)dy=0 through (1,0)(1,0)(1,0).

Try the method on paper first. The full solution is available whenever you need it.

Show the step-by-step solution
  1. 1

    Test and integrate

    My=Nx=1M_y=N_x=1My​=Nx​=1. Integrating MMM gives F=x2+xy+g(y)F=x^2+xy+g(y)F=x2+xy+g(y).

  2. 2

    Match N

    Fy=x+g′(y)=x+2yF_y=x+g'(y)=x+2yFy​=x+g′(y)=x+2y, so g=y2g=y^2g=y2.

  3. 3

    Use the point

    F(1,0)=1F(1,0)=1F(1,0)=1.

RESULTx2+xy+y2=1x^2+xy+y^2=1x2+xy+y2=1

Check the answer

The differential is (2x+y)dx+(x+2y)dy(2x+y)dx+(x+2y)dy(2x+y)dx+(x+2y)dy.

Avoid this mistake

Integrating M in x does not make all y-dependent terms disappear: they belong in g(y).
