Linear systems and eigenvectors

Solve coupled equations by identifying independent directions of motion.

Before you start: Matrix multiplication, determinants, and characteristic roots.

UnderstandMethodExample 1Example 2Your turnAvoid this mistake

THE IDEA

Understand before calculating

Write the matrix form

A system such as x′=ax+byx'=ax+byx′=ax+by, y′=cx+dyy'=cx+dyy′=cx+dy is X′=AX,X=(xy),A=(abcd).\mathbf X'=A\mathbf X,\qquad \mathbf X=\begin{pmatrix}x\\y\end{pmatrix},\quad A=\begin{pmatrix}a&b\\c&d\end{pmatrix}.X′=AX,X=(xy​),A=(ac​bd​). Each row reproduces one differential equation.

An eigenvector keeps its direction

Try X=eλtv\mathbf X=e^{\lambda t}\mathbf vX=eλtv. Substitution gives Av=λvA\mathbf v=\lambda\mathbf vAv=λv. Find eigenvalues from det⁡(A−λI)=0\det(A-\lambda I)=0det(A−λI)=0, then a nonzero vector in the nullspace for each eigenvalue.

Combine independent modes

Two independent real eigenvectors give X=C1eλ1tv1+C2eλ2tv2.\mathbf X=C_1e^{\lambda_1t}\mathbf v_1+C_2e^{\lambda_2t}\mathbf v_2.X=C1​eλ1​tv1​+C2​eλ2​tv2​. Initial values produce a small linear system for C1,C2C_1,C_2C1​,C2​. A negative real eigenvalue gives decay in its mode; a positive one gives growth.

Complex or repeated eigenvalues

For λ=α+iβ\lambda=\alpha+i\betaλ=α+iβ, v=p+iq\mathbf v=\mathbf p+i\mathbf qv=p+iq, take real and imaginary parts: eαt(pcos⁡βt−qsin⁡βt)e^{\alpha t}(\mathbf p\cos\beta t-\mathbf q\sin\beta t)eαt(pcosβt−qsinβt) and eαt(psin⁡βt+qcos⁡βt)e^{\alpha t}(\mathbf p\sin\beta t+\mathbf q\cos\beta t)eαt(psinβt+qcosβt). If a repeated eigenvalue has only one eigenvector v\mathbf vv, find w\mathbf ww with (A−λI)w=v(A-\lambda I)\mathbf w=\mathbf v(A−λI)w=v. A second solution is eλt(tv+w)e^{\lambda t}(t\mathbf v+\mathbf w)eλt(tv+w).

Your method checklist

  1. Write the coefficient matrix and characteristic determinant.
  2. Find eigenvalues and independent eigenvectors.
  3. Build a real general solution, using generalized vectors if needed.
  4. Apply the initial vector and verify each component equation.

One eigenvector for a repeated eigenvalue

Find the general solution for A=(1101)A=\begin{pmatrix}1&1\\0&1\end{pmatrix}A=(10​11​).

  1. 1

    Find the eigenvector

    The repeated eigenvalue is 1. The equation (A−I)v=0(A-I)\mathbf v=0(A−I)v=0 gives v=(1,0)T\mathbf v=(1,0)^Tv=(1,0)T.

  2. 2

    Find a generalized eigenvector

    Choose w=(0,1)T\mathbf w=(0,1)^Tw=(0,1)T, since (A−I)w=v(A-I)\mathbf w=\mathbf v(A−I)w=v.

  3. 3

    Build the two modes

    Use etve^t\mathbf vetv and et(tv+w)e^t(t\mathbf v+\mathbf w)et(tv+w).

TRY IT YOURSELF

Your turn

Solve x′=−yx'=-yx′=−y, y′=xy'=xy′=x, with x(0)=1x(0)=1x(0)=1, y(0)=0y(0)=0y(0)=0.

Try the method on paper first. The full solution is available whenever you need it.

Show the step-by-step solution
  1. 1

    Eliminate one variable

    Differentiating x′=−yx'=-yx′=−y gives x′′=−y′=−xx''=-y'=-xx′′=−y′=−x. Also x′(0)=−y(0)=0x'(0)=-y(0)=0x′(0)=−y(0)=0.

  2. 2

    Recover both components

    x=cos⁡tx=\cos tx=cost. Then y=−x′=sin⁡ty=-x'=\sin ty=−x′=sint.

RESULTx=cos⁡t,y=sin⁡tx=\cos t,\qquad y=\sin tx=cost,y=sint

Check the answer

x2+y2=1x^2+y^2=1x2+y2=1, so the trajectory is a circle. The eigenvalues are ±i\pm i±i.

Avoid this mistake

An eigenvector must be nonzero. Multiplying it by a nonzero constant changes its representation, not its direction.
