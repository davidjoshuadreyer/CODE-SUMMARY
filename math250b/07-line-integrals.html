07 · Vector fields and line integrals

Compute divergence and curl, parameterize a path, and recognize conservative fields.

Divergence is scalar; curl is a vector

For F=⟨P,Q,R⟩\mathbf F=\langle P,Q,R\rangleF=⟨P,Q,R⟩, ∇⋅F=∂P∂x+∂Q∂y+∂R∂z.\nabla\cdot\mathbf F=\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}.∇⋅F=∂x∂P​+∂y∂Q​+∂z∂R​. Curl measures local rotation: ∇×F=⟨Ry−Qz, Pz−Rx, Qx−Py⟩.\nabla\times\mathbf F=\left\langle R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\right\rangle.∇×F=⟨Ry​−Qz​, Pz​−Rx​, Qx​−Py​⟩. Do not add all nine partial derivatives for divergence.

Scalar integrals use speed

For a smooth path r(t)\mathbf r(t)r(t), a≤t≤ba\le t\le ba≤t≤b, ∫Cf ds=∫abf(r(t))∥r′(t)∥ dt.\int_C f\,ds=\int_a^b f(\mathbf r(t))\|\mathbf r'(t)\|\,dt.∫C​fds=∫ab​f(r(t))∥r′(t)∥dt. Reversing the direction of travel does not change this scalar integral. For a line segment from AAA to BBB, use r(t)=A+t(B−A)\mathbf r(t)=A+t(B-A)r(t)=A+t(B−A), with 0≤t≤10\le t\le10≤t≤1.

Work integrals use a dot product

A vector line integral is ∫CF⋅dr=∫abF(r(t))⋅r′(t) dt.\int_C\mathbf F\cdot d\mathbf r=\int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt.∫C​F⋅dr=∫ab​F(r(t))⋅r′(t)dt. Here the direction of the path matters: reversing it changes the sign. In two dimensions the same integral is written ∫CP dx+Q dy\int_C P\,dx+Q\,dy∫C​Pdx+Qdy.

A potential replaces the path calculation

If F=∇Φ\mathbf F=\nabla\PhiF=∇Φ, then ∫CF⋅dr=Φ(B)−Φ(A).\int_C\mathbf F\cdot d\mathbf r=\Phi(B)-\Phi(A).∫C​F⋅dr=Φ(B)−Φ(A). Find Φ\PhiΦ by integration, retaining an unknown function of the other variables, then match the remaining components. A continuously differentiable curl-free field on a simply connected open domain is conservative. A hole or singularity in the domain can invalidate the shortcut from zero curl alone.

WORKED EXAMPLE

For F=⟨2xy,x2+2y⟩\mathbf F=\langle2xy,x^2+2y\rangleF=⟨2xy,x2+2y⟩, integrate the first component with respect to xxx: Φ=x2y+g(y)\Phi=x^2y+g(y)Φ=x2y+g(y). Matching Φy=x2+g′(y)=x2+2y\Phi_y=x^2+g'(y)=x^2+2yΦy​=x2+g′(y)=x2+2y gives Φ=x2y+y2\Phi=x^2y+y^2Φ=x2y+y2. The work from (0,0)(0,0)(0,0) to (1,2)(1,2)(1,2) is Φ(1,2)−Φ(0,0)=2+4=6.\Phi(1,2)-\Phi(0,0)=2+4=6.Φ(1,2)−Φ(0,0)=2+4=6.
