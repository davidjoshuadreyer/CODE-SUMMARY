How a dielectric changes the other capacitor’s field

  2. Parallel connection

    Each capacitor has the full battery voltage. E2=V/d2E_2=V/d_2E2​=V/d2​ before and after, so E2′/E2=1E_2'/E_2=1E2′​/E2​=1.
