    Take the negative gradient, differentiating one coordinate at a time.

  2. Set up

    Ex=−2Axy+By2; Ey=−Ax2+2Bxy; Ez=0E_x=-2Axy+By^2;\ E_y=-Ax^2+2Bxy;\ E_z=0Ex​=−2Axy+By2; Ey​=−Ax2+2Bxy; Ez​=0.

QUESTION 3 · Homework 7 · 24.12

Cylindrical capacitor

Exact question and original solution screenshots ↗

  1. Identify

    Integrate the radial field between coaxial conductors.

  2. Set up

    V=λln⁡(b/a)/(2πε0); C/L=2πε0/ln⁡(b/a); Q=(C/L)LVV=\lambda\ln(b/a)/(2\pi\varepsilon_0);\ C/L=2\pi\varepsilon_0/\ln(b/a);\ Q=(C/L)LVV=λln(b/a)/(2πε0​); C/L=2πε0​/ln(b/a); Q=(C/L)LV.

  3. Execute

    C/L=1.20×10−10 F/m; Q=1.17×10−10 CC/L=1.20\times10^{-10}\ \mathrm{F/m};\ Q=1.17\times10^{-10}\ \mathrm CC/L=1.20×10−10 F/m; Q=1.17×10−10 C.
