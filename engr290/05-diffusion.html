05 · Diffusion and assignment practice

Solve diffusion-time problems with clear assumptions and units.

How atoms move

Vacancy diffusion involves an atom jumping into a neighbouring vacant site. Interstitial diffusion moves atoms between interstitial positions. Diffusivity commonly follows D = D₀ exp(−Q/RT) for molar activation energy Q; use k instead of R for energy per atom. Increased temperature generally increases D.

Steady diffusion

Fick’s first law is J = −D dC/dx. The minus sign indicates transport down the concentration gradient. With constant D and a linear profile through a slab, J = −D(C₂ − C₁)/L. If C is in kg/m³, flux is kg/(m²·s).

A changing concentration profile

For a semi-infinite solid with uniform initial concentration C₀, constant surface concentration Cₛ, and constant D: (C(x,t) − C₀)/(Cₛ − C₀) = 1 − erf[z], where z = x/(2√(Dt)). Find z from an error-function table, then t = x²/(4Dz²). This model assumes a sufficiently thick body so the far boundary has no influence.

Read the table carefully

An erf table and an erfc table are different: erfc(z) = 1 − erf(z). Normalize concentrations first, then select the matching table value. For fixed normalized concentration and D, time scales with depth squared. Convert millimetres to metres before using D in m²/s.

WORKED EXAMPLE

Assignment-style carburizing: Cₛ = 1.0 wt %, C₀ = 0.2 wt %, target C = 0.6 wt %, x = 0.001 m, and D = 2.98 × 10⁻¹¹ m²/s. The normalized concentration is 0.5, so erf(z) = 0.5 and z ≈ 0.4769. Thus t = 0.001²/[4(2.98 × 10⁻¹¹)(0.4769)²] ≈ 3.69 × 10⁴ s ≈ 10.25 h.

Check your understanding

At the same temperature and target concentration, how long would reaching 2 mm take?

Show the worked answer

Doubling depth multiplies time by four: about 41.0 h. This assumes the semi-infinite model remains valid.
