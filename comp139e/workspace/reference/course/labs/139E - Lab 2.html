Computing Grades - Input Validation and Selection Statements

Computing the final mark and grade for a course entails the computation of the weighted average of several contributing marks and the determination of a letter grade based on the conversion of the mark in percentage.

Assignment

Write a C++ application that will compute the final mark and letter grade for the weighted average of several marks:

  1. The number of marks is NOT entered by the user. Instead, the entry of marks is terminated by entering a non-numeric character (such as q) when the user is prompted for a mark or a weight.
  2. Your program must perform input validation:
    The permissible range for a mark is 0.0 to 100.0 (inclusive).
    The permissible range for a weight is 1.0 to 50.0 (inclusive).
    N.B.:
    1. The numbers for these permissible ranges must be named constants in your program. i.e., do not put numbers like 50.0 inside of your function.
    2. Write a function to validate the input: 
      
/**
 * A reusable function for getting validated in-range numbers.
 * Repeatedly asks for the value if an out-of-range number gets entered
 *
 * @param prompt A string such as "Enter the mark"
 * @param number A pointer to the number we are trying to read
 * @param min The minimum permissible value
 * @param max The maximum permissible value  
 *
 * @return true if the input contains only numeric characters, false otherwise
 */
bool getValidNumber(string prompt, double *value, const double min, const double max);
      If the user enters an out-of-range value, this function must print a message, prompt again, and read the number again (run my program, below).
      Note that this function does not know that it is being used for marks, weights, or even potatoes! It just prints the prompt, puts the value in your variable, does a range check, etc.
  3. Your program must check that the weights add up to 100%, with an allowable error of 0.1% Use named constants.
  4. Do NOT use any arrays.
  5. Write a function that uses the Camosun College conversions to get the letter grades (this is on the course outline). Note that your function must return a string and that string will be printed from your main() ... do not print from inside of the function. The function declaration is: 
    
string gradeFromMark(const double mark);
    Since you are comparing ranges, use an if-elseif-else chain. Although it would be better to do so, you don't need need to use named constants for this function ... saving you from some tedium.

Run my program (below) to get a better idea of what you need to accomplish. Be sure to try some invalid values!
