Files and Text Processing

Computer programs are often used to parse files containing various types of data. For example, a text file could contain words and integers that need to be separated.

However, as the file is processed, we can't predict if the next character to be processed is numeric or alphabetic...

Assignment

Write a C++ program that processes a text file such that:
  1. The name of the input file and the name of the output file are specified on the command line (i.e., using argv and argc).
  2. The output file is opened using append mode.
  3. White space is ignored
  4. Words are printed one per line, preceded by the identifier "Found a xx character word: ", where xx is the length of the word.
  5. Classify by peeking only at the first character and then read in the entire word (as a string) or number (as an integer). Note that integers must be read from the file directly into an int variable.
  6. You are only allowed to look at one character to make this classification! (There is another way, but I want you to try this way...)
  7. Integer numbers are printed one per line, preceded by the identifier "Found an integer: "
  8. You can assume that the input file contains only textual words and valid integers (no floating-point).
  9. There are some useful functions here
You must use object-oriented C++ strings and C++ string functions.
