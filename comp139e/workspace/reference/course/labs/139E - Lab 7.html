Using the Standard Template Library

We have seen the power and flexibility of the C++ STL, and now it is time to exercise this power.

And, as a bonus, we get to use the code from the Shapes example from class so that you can see polymorphism in action!

Assignment

  1. Create a new C++ project and copy all of the following files into your project. These are the complete files for the Shape example that we did in class. You can use the main() for some ideas, but it is NOT part of this lab.

    Shape.hpp Circle.cpp Rectangle.cpp Circle.hpp Rectangle.hpp shapeMain.cpp

  2. Write a new main() and create a vector that stores pointers to Shapes.
  3. Use all of the following vector methods in some useful manner:
    push_back, [], front, back, size, capacity, insert, pop_back, at, max_size.
    Here is a link to a C++ reference. Be sure to look at it!
  4. After you put some Shapes into the vector, write a for loop that uses iterators to draw all of the Shapes. You will need to use begin() and end() for this. Be sure to step the iterator through the vector. (Remember that the iterator acts like a "smart" pointer to the item stored in the vector, which in our case is a Shape*)
  5. Be sure to use your vector operations inside of a try so that you can catch any useful exceptions that might be thrown. You will need to look at the documentation for the vector functions to see what exceptions that you will need to catch. There is one particularly useful exception...
  6. Do something that will cause a "useful" exception from a vector class function to be thrown so that you can catch it.
  7. Your program does not need to be interactive. i.e., it does not need to get input from the user. You can simply write code that exercises your vector<Shape*>, similar to the main() in the MathVector lab.
