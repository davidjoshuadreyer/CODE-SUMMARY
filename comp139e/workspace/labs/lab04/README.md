# Lab 04: Files and text processing

Implement the file-opening/argument handling in `lab.cpp` and parsing in `text_processing.cpp`. `run(argc, argv)` receives input in `argv[1]` and output in `argv[2]`; check `argc == 3`. Open output in append mode. Classify by peeking once after whitespace, then read directly into a string or int. `data/textAndNumbers.txt` and `data/results.txt` are supplied input and expected output. Write your results to `output.txt`, not the supplied expected-output file.
