# Lab 03: Spherical coordinates

Implement the two conversions in `spherical.cpp` and the inline `getRadius` in `spherical.hpp`. Default arguments for 2-D calls are already declared. Return a fresh dynamically allocated array for each spherical-to-rectangular call. `testTrigMain.cpp` is an unchanged instructor file; CMake renames its entry point during compilation so `lab03::run` can call it. Do not edit the tests. TODO exceptions stop testing until you implement the functions; then inspect all seven test results. The instructor driver always returns EXIT_SUCCESS even if comparisons fail.
