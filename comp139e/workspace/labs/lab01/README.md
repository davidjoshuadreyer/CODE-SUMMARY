# Lab 01: Surveying and streetlights

Implement the suggested calculation helpers in `survey.cpp`, then call them from `lab.cpp`. The supplied input/output helpers are already implemented in `survey.cpp` (wrapped in `lab01`, with a portable PI constant). Allocate arrays after determining the number of lights; include a light at both endpoints. Validate input and release arrays when finished. The suggested helper names are organizational choices, not mandated by the handout.
