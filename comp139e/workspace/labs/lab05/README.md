# Lab 05: Digital controllers

Then select the PID controller in `controllerMain.cpp` using its commented example. That file now defines `lab05::run()` instead of `main()`. Original supplied files remain in `reference/course/labs/files/DigitalController/`. The full handout is `DigitalControl.pdf` in that directory; use its leaky-integral equation.
