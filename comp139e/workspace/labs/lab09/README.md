# Lab 09: Numerical integration (MATLAB)

Implement `simpsonsRuleSum.m` and `simpsonsRuleLoop.m`. The supplied trapezoidalRule and integrationError files have been extracted unchanged from Lab9.zip. Open this folder in MATLAB and run `integrationError`. The first implementation uses sum without loops; the second uses loops and if-else without sum. Require an even integer interval count greater than one. See `../../reference/course/labs/COMP 139 Lab Assignment #9.pdf`.
