# Lab 07: STL vectors and shapes

Write your vector exercise in `lab.cpp`, using the shapes in `../common/shapes/`. Exercise push_back, [], front, back, size, capacity, insert, pop_back, at, and max_size. Iterate with begin/end, draw the shapes, and intentionally cause and catch a useful vector exception. Keep pointed-to shapes alive while using them and release any heap allocations.
