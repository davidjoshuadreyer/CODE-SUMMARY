# Lab 02: Weighted grades

Implement `lab02::getValidNumber` and `lab02::gradeFromMark` in `grades.cpp`. Use the named constants in `grades.hpp`. In `lab.cpp`, accumulate marks and weights without arrays, stop on non-numeric input, check the total weight, and print the returned grade. Check the course outline for letter-grade boundaries.
