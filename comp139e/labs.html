Lab 01 · C++

Surveying & streetlights

Lab 03 · C++

Spherical coordinates

Lab 03: Spherical coordinates

Implement the two conversions in spherical.cpp and the inline getRadius in spherical.hpp. Default arguments for 2-D calls are already declared. Return a fresh dynamically allocated array for each spherical-to-rectangular call. testTrigMain.cpp is an unchanged instructor file; CMake renames its entry point during compilation so lab03::run can call it. Do not edit the tests. TODO exceptions stop testing until you implement the functions; then inspect all seven test results. The instructor driver always returns EXIT_SUCCESS even if comparisons fail.

Files & text processing

Lab 04: Files and text processing

Implement the file-opening/argument handling in lab.cpp and parsing in text_processing.cpp. run(argc, argv) receives input in argv[1] and output in argv[2]; check argc == 3. Lab 06 · C++

Linked stacks

Lab 06: Linked stacks and shapes

Implement push, pop, and top in Stack.hpp; these are templates and must stay in the header. Replace the temporary TODO exceptions with real operations, using StackException for empty-stack errors. Implement the Square display functions in Square.cpp; its constructor already forwards equal dimensions to Rectangle. Write the driver in lab.cpp using Stack<Shape*>, exercise every operation, and demonstrate a caught exception. Shared shapes are in ../common/shapes/. The original shapeMain.cpp is in the course reference files. Drain allocated nodes and manage shape lifetimes; the starter stack, like the supplied one, does not clean up remaining nodes or define copying.
