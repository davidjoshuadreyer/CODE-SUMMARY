Start with Lesson 1 · How to read C++

Brand new? Read this first
  1. A program is a set of instructions. C++ normally starts in a function named main().
  2. A variable is a named place to store a value. int age = 20; stores the whole number 20 under the name age.
  3. cout << age; displays that value. cin >> age; reads a value from your input.
  4. ; usually ends a statement. { } group code. // starts a note for people.
  5. Predict what will happen, run the program, then change one thing and run again. Compiling means checking your C++ and translating it into a runnable program. A compiler error is feedback about what needs fixing.

Course examples often put main() in online_main.cpp. It calls the lesson's function for you. A .hpp or .h file usually declares what is available; a .cpp file usually contains the instructions.
