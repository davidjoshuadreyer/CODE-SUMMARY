Open the workspace

Use your existing Template/COMP139E folder, or extract the download and open the extracted COMP139E folder in VS Code. The download includes sources and configuration; build it on your computer to create the executables.

Requirements: Python 3.10 or later, Visual Studio C++ Build Tools with CMake, and the Microsoft C/C++ extension for VS Code debugging. MATLAB is needed for the original MATLAB assignments.

Build and launch

In VS Code, press Ctrl+Shift+B to build. Then choose Terminal → Run Task → Open course dashboard. Alternatively, run these commands in a PowerShell terminal opened in the COMP139E folder:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dashboard.ps1

Keep that terminal open, then visit http://127.0.0.1:13900. If the page cannot connect, start the dashboard first. It runs on the computer where you started it.

Use the live console

  1. Choose a lab, tutorial, or reference example.
  2. Select Run program. Use example input where available.
  3. Send keyboard input, finish input with EOF, or stop a running program.
  4. Edit the source in VS Code, then select Build programs to run the updated code.
  5. Read related headers and generated files beside the console.

The online Code Desk compiles C++ through Judge0 and accepts input before each run. The optional local dashboard also supports a live interactive console and desktop debugging.

Debug or use the terminal

.\build\bin\main.exe tutorial 5
.\build\bin\main.exe example TestCircleWithHeader
.\build\bin\main.exe 2

With no command-line selector, ACTIVE_EXAMPLE takes priority, followed by ACTIVE_TUTORIAL, then ACTIVE_LAB in main.cpp. Press F5 to use the supplied debugger configuration.
