Open and run

  1. Extract the ZIP.
  2. Open Lab05.sln in Visual Studio.
  3. Press Ctrl+F5. The unchanged main runs the proportional controller.
  4. To run PID, follow the outline to uncomment the two existing PID lines in the supplied main.
  5. Open plotResponse.m in MATLAB and run it to show the step-response plot.

Requires Visual Studio with C++ tools. The project uses the default toolset rather than requiring v143. If prompted, retarget to an installed toolset and Windows SDK.

Included

  • PID_Controller.hpp / .cpp — the two required solution files.
  • All six supplied C++ files, unchanged — ready to build together.
  • IMPLEMENTATION.html — file map, formula explanation, and requirements checklist.
  • plotResponse.m, pidOutput.txt, and plot preview — the MATLAB plotting step and verified results.
Requirements and checks

The unchanged main matches the supplied proportional output. A temporary test copy activating the original PID lines matches all 50 supplied PID output rows. Additional tests check saved state, independent controller objects, zero gain, zero error, and calling through Controller*.

The lab asks for the two documented PID files and a MATLAB plot. The package includes both files and the ready-to-run plotting script. C++ was compiled and run with Clang C++17; Visual Studio and MATLAB execution were not available here.
