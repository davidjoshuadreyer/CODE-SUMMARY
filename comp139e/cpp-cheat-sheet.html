1. Default class structure

class Rectangle {
private:
    double length, width; // object data
public:
    Rectangle();         // constructor
    void setLength(double x);
    double getArea() const;
}; // semicolon required

Rectangle::Rectangle() {
    length = 1;
    width = 1;
}
void Rectangle::setLength(double x) {
    length = x;
}
double Rectangle::getArea() const {
    return length * width;
}

Outside-class definition:

returnType Class::function(parameters) {
    // body
}

Constructor: class name, no return type—not even void. Class:: says which class owns the function.

Declaration gives the signature and ends in ;. Definition supplies the body. Return type, parameter types, and trailing const must agree.

A trailing const promises not to modify ordinary object data; it allows calls on const objects.

2. What is defined where?

LocationMeaning
Inside class, outside methodsMembers: data stored in each object
Function parenthesesParameters: receive the arguments
Function bodyLocal variables: belong to that call
main()Create objects, call functions, use results
new T[n]Allocation survives until matching deletion

Inside a method, length means this object's member. If a parameter has the same name, use this->length for the member.

class defaults to private access; struct defaults to public. Both can contain data and methods.

3. Value, reference, or pointer?

ParameterMeaning / call
void f(int x)Copy of value; f(n)
void f(int &x)Alias to caller's variable; f(n)
void f(int *p)Copy of address; f(&n)
void f(const int &x)Read through a reference; f(n)
int n = 5;
int *p = &n; // &n: address of n
*p = 7;      // *p: value at that address
             // n is now 7

T &x in a declaration means reference. &x in an expression means address-of. T *p declares a pointer; *p dereferences one.

Changing *p changes the pointed-to value. Reassigning a by-value pointer parameter p does not redirect the caller's pointer. T *&p can.

4. Dot or arrow?

Rectangle r;
Rectangle *p = &r;
Rectangle *items = new Rectangle[3];

r.getArea();         // object → dot
p->getArea();        // pointer → arrow
(*p).getArea();       // equivalent
items[i].getArea();  // element is object
(items+i)->getArea();// address is pointer

delete[] items;

Look immediately left of the operator. items is a pointer; items[i] is an object.

6. Dynamic array pattern

// Input is read-only. Caller owns result.
double *doubled(const double *values,
                int size) {
    double *result = new double[size];
    for (int i = 0; i < size; ++i) {
        result[i] = values[i] * 2;
    }
    return result;
}

// In main():
double values[] = {2, 3};
double *out = doubled(values, 2);
cout << out[0];
delete[] out;
out = nullptr;
  • new double[size] produces a double*, not one double. Its elements are uninitialized until assigned; new double[size]{} zero-initializes them.
  • a[i] is equivalent to *(a + i).
  • &a[i] is equivalent to a + i.
  • Valid indexes: 0 through size - 1. Use i < size.
  • Pass the length separately: a pointer does not carry the array size.
  • A runtime array length must have an integer type; do not use double num.

7. Memory ownership

AllocationRelease
new Tdelete p;
new T[n]delete[] p;
T a[3]; local arrayNo manual delete

Never return a pointer/reference to a local variable or local array. Its lifetime ends when the function returns.

Delete each owned allocation once. Do not use it afterward. Setting one pointer to nullptr neither frees memory nor clears other pointers to that allocation.

8. Numeric and function rules

(3 + 8) / 2                       // 5
static_cast<double>(3 + 8) / 2  // 5.5

Convert before integer division. Converting the truncated result afterward cannot recover the fraction.

  • void: no returned value. A non-void function must return its result on every relevant path.
  • Default arguments fill omitted trailing arguments; normally specify them once, in the declaration.
  • Overloads differ in parameter lists; return type alone is not enough.
  • static local variables retain their values between calls.

9. Strings and static members

string name = "Ada Lovelace";
auto space = name.find(' ');
if (space != string::npos) {
    cout << name.substr(0, space);
}

find returns a position or string::npos. substr(start, count) uses a character count, not an ending index. length() gives the number of characters.

// Inside class Student:
static int created;
static int count() { return created; }

// Outside class, define storage once:
int Student::created = 0;

// Call via class:
Student::count();

A static member is shared by the class. A static method has no this object; it cannot directly access an ordinary member without an object.

10. File streams

#include <fstream>

ofstream output("data.txt");
if (!output) return 1;
output << 2.5 << ' ' << 4.0;
output.close();

ifstream input("data.txt");
if (!input) return 1;
double value, total = 0;
while (input >> value) {
    total += value;
}
if (input.bad() || !input.eof()) {
    // read error / non-numeric input
}

ofstream writes with <<; ifstream reads with >>. Test the read itself—not while (!input.eof()). Use getline(input, line) for a complete line.

11. Exceptions

#include <stdexcept>

try {
    if (count <= 0)
        throw invalid_argument("bad count");
    cout << total / count;
} catch (const invalid_argument &error) {
    cout << error.what();
}
// Continue here after the handler.

throw skips the remaining normal path and searches for a matching catch. Catch standard exceptions by const reference; what() gives their message.

Final 30-second check

  1. Declarations and definitions match.
  2. Constructor has no return type.
  3. Each call supplies the correct types.
  4. Dot/arrow matches object/pointer.
  5. Indexes stay inside the array.
  6. Every owned allocation has matching cleanup.
  7. Trace one small input to check the result.
