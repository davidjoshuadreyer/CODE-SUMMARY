Where does code go?

Top of the file
#include lines for the libraries you use.
Above main() / in a header
Structs, classes, function declarations and template definitions. Wrap a header in #ifndef NAME_HPP, #define NAME_HPP and #endif.
Inside main()
Create objects and call functions. This is where the “Usage” code goes.
Outside the class
Separate method definitions use ClassName::. Template methods also repeat template<typename T> and use ClassName<T>::.

Each card is independent. Combine only the pieces you need; keep one main() and one definition of each class or function.

Linked lists, stacks & queues

Singly linked list: IntSLList

You need to insert at either end and remove the head.

# Link
TemplatePaste above main(), or in a header.
#include <iostream>
using namespace std;
class IntSLLNode {
public:
    IntSLLNode(int el, IntSLLNode *ptr = nullptr) { info = el; next = ptr; }
    int info;
    IntSLLNode *next;
};
class IntSLList {
    IntSLLNode *head, *tail;
public:
    IntSLList() { head = tail = nullptr; }
    int isEmpty() { return head == nullptr; }
    void addToHead(int el) {
        head = new IntSLLNode(el, head);
        if (tail == nullptr) tail = head;
    }
    void addToTail(int el) {
        if (tail != nullptr) {
            tail->next = new IntSLLNode(el);
            tail = tail->next;
        } else head = tail = new IntSLLNode(el);
    }
    int deleteFromHead() { 
        int el = head->info;
        IntSLLNode *tmp = head;
        if (head == tail) head = tail = nullptr;
        else head = head->next;
        delete tmp;
        return el;
    }
    ~IntSLList() { while (!isEmpty()) deleteFromHead(); }
    
    IntSLList(const IntSLList&) = delete;
    IntSLList& operator=(const IntSLList&) = delete;
};
What it does · What to change
IntSLLNode
info stores the integer; next links to the following node.
head / tail
First and last node; both null when empty.
addToHead / addToTail
Update links, then update the relevant end pointer.
deleteFromHead
Save the value and node, update links, delete the old node, return the value.

What to change

Use the same pointer steps for other node data. Add traversal with for (IntSLLNode* p = head; p != nullptr; p = p->next) inside the class.

Remember

deleteFromHead requires a nonempty list. Destructor frees nodes; copying is disabled to avoid shared raw ownership.

Lab 6 linked Stack<T>

You need LIFO: last in, first out.

# Link
TemplatePaste above main(), or in a header.
#include <iostream>
#include <exception>
#include <string>
using namespace std;

class StackException : public exception {
    string message;
public:
    explicit StackException(const string& msg) noexcept : message(msg) {}
    const char* what() const noexcept override { return message.c_str(); }
};

template <class T> class Stack {
private:
    typedef struct stackNode {
        struct stackNode *next;
        T theItem;
    } StackNode;
    StackNode *topOfStack;
    int count;
public:
    Stack() : topOfStack(NULL), count(0) {}
    void push(T item) {
        StackNode *newNode = new StackNode;
        newNode->theItem = item;
        newNode->next = topOfStack;
        topOfStack = newNode;
        ++count;
    }
    T pop(void) {
        if (isEmpty()) throw StackException("Pop from empty stack");
        T item = topOfStack->theItem;
        StackNode *old = topOfStack;
        topOfStack = old->next;
        delete old;
        --count;
        return item;
    }
    T top(void) {
        if (isEmpty()) throw StackException("Top of empty stack");
        return topOfStack->theItem;
    }
    int size(void) { return count; }
    bool isEmpty(void) { return count == 0; }
    
    ~Stack() { while (!isEmpty()) pop(); }
    Stack(const Stack&) = delete;
    Stack& operator=(const Stack&) = delete;
};
What it does · What to change
StackNode / theItem / next
A node holds one item and the link below it.
topOfStack / count
The top node and the current item count.
push
Create a node, link to old top, move top, increment count.
pop
Save the item, advance top, delete the old node, decrement count, return item.
top / isEmpty / size
Inspect without removing; empty access throws StackException.

What to change

Choose Stack<double>, Stack<std::string> or Stack<Shape*>. For Shape*, delete each owned shape after popping it; deleting nodes alone does not delete the pointed-to shapes.

Remember

This uses the lab API: pop returns T. Keep template code in the header. Cleanup and disabled copying are practice additions.

Circular queue: ArrayQueue<T, size>

You need FIFO in a fixed-size array.

# Link
TemplatePaste above main(), or in a header.
#include <iostream>
using namespace std;

template<class T, int size = 100>
class ArrayQueue {
public:
	ArrayQueue() {
		first = last = -1;
	}
	void enqueue(T);
	T dequeue();
	bool isFull() {
		return (first == 0 && last == size-1) || (first == last + 1);
	}
	bool isEmpty() {
		return first == -1;
	}

private:
	int first, last;
	T storage[size];
};

template<class T, int size>
void ArrayQueue<T,size>::enqueue(T el) {
	if (!isFull())
		if (last == size-1 || last == -1) {
			storage[0] = el;
			last = 0;
			if (first == -1)
				first = 0;
		}
		else storage[++last] = el;
	else cout << "Full queue.\n";
}

template<class T, int size>
T ArrayQueue<T,size>::dequeue() {
	T tmp;
	tmp = storage[first];
	if (first == last)
		last = first = -1;
	else if (first == size-1)
		first = 0;
	else first++;
	return tmp;
}
What it does · What to change
storage[size]
Fixed array of queue elements.
first / last
Oldest and newest occupied indexes; -1 marks empty.
enqueue
Check full, wrap last if needed, store the value.
dequeue
Save the front value; reset if it was the last item, otherwise advance/wrap first.

What to change

Change <int, 4> to the item type and capacity you need. Keep the supplied first/last convention.

Remember

Call dequeue only when nonempty. A full enqueue prints “Full queue.” and does not insert; it does not throw.

Read numbers from a file

You need to process every successfully read value.

# Link
TemplatePaste above main(), or in a header.
#include <fstream>
#include <stdexcept>
#include <string>

double totalFile(const std::string& filename) {
    std::ifstream input(filename);
    if (!input) throw std::runtime_error("Cannot open file");
    double value, total = 0;
    while (input >> value) {
        total += value;
    }
    if (input.bad() || !input.eof()) {
        throw std::runtime_error("Invalid data or read error");
    }
    return total;
}
What it does · What to change
ifstream
Input file stream; check opening before reading.
while (input >> value)
Run the body only after a successful read.
State check
Distinguish the expected end of the file from other failure.

What to change

Change the input type and replace total += value with your processing. For whole lines use std::getline(input, line) and a std::string line.

Remember

Do not loop on !input.eof(). Local streams close when they leave scope. The usage example creates a sample file.

Write or append a file

You need to save results without erasing earlier entries.

# Link
TemplatePaste above main(), or in a header.
#include <fstream>
#include <stdexcept>
#include <string>

void appendValue(const std::string& filename, double value) {
    std::ofstream output(filename, std::ios::app);
    if (!output) throw std::runtime_error("Cannot open file");
    output << value << '\n';
    output.close();
    if (!output) throw std::runtime_error("Cannot write file");
}
What it does · What to change
ofstream
Output file stream.
ios::app
Append to existing contents.
close and check
Finish writing and check for failure.

What to change

Remove std::ios::app to replace the file contents. Change the output expression to write fields separated by spaces.

Remember

Ordinary ofstream opening overwrites existing contents; choose the mode deliberately.

Throw and catch an exception

An invalid operation must be reported to the caller.

TemplatePaste above main(), or in a header.
#include <iostream>
#include <stdexcept>

double quotient(double numerator, double denominator) {
    if (denominator == 0) {
        throw std::runtime_error("Cannot divide by zero");
    }
    return numerator / denominator;
}
What it does · What to change
throw
Stop the current operation and transfer control to a matching handler.
try
Wrap calls that may throw.
catch by const reference
Read the exception without slicing it.
what()
Retrieve the error message.

What to change

Change the invalid condition and message; replace quotient with your own operation.

Remember

Statements after a throw in the try block are skipped. An ordinary file-stream failure usually sets flags rather than throwing.
