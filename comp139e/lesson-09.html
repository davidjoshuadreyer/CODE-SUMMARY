09 · Templates

Templates leave the type open until use

Learn the idea

Box<int> stores an integer; Box<double> stores a double. The type used with larger must support >. Templates do not make every operation valid for every type. Shared template definitions normally belong in headers; see the example in LearningStack.hpp.

The example, in plain English

A template is a recipe that works with different types.

Instead of writing nearly identical functions for int and double, a type parameter lets one definition serve both.

Try this: Compare calls using whole numbers and decimal numbers.

/*
 * LESSON 9: Function templates and class templates.
 * Prerequisite: 3 and 7. Run: main.exe tutorial 9
 * Expect: 7, 4.5, then stored value = 12.
 * Try: make a Box<string> (include <string>) and store your name.
 * Connects to Lab 6. T is a placeholder for the type chosen by the caller.
 */
#include "Tutorials.hpp"
#include <iostream>
using namespace std;

namespace tutorial09 {
template <typename T>
T larger(T first, T second)
{
    if (first > second) return first;
    return second;
}

template <typename T>
class Box {
private:
    T value;
public:
    Box(T initialValue) : value(initialValue) {}
    T get() const { return value; }
};
// Templates normally go in headers when shared between source files, because
// the compiler needs their definitions to generate code for each chosen type.
}

int tutorials::templates()
{
    cout << tutorial09::larger(3, 7) << endl;
    cout << tutorial09::larger(2.5, 4.5) << endl;
    tutorial09::Box<int> box(12);
    cout << "Stored value = " << box.get() << endl;
    return 0;
}
