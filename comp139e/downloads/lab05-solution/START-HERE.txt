LAB 5 — DIGITAL PID CONTROLLER

1. Extract this entire ZIP to a normal folder (do not run inside the ZIP).
2. Open Lab05.sln in Visual Studio with the Desktop development with C++ workload.
3. Press Ctrl+F5. There is only one project and one main().
4. The unchanged supplied main runs the PROPORTIONAL controller and prints
   Y = [ ... ]; with 50 rows and two columns.
5. Open IMPLEMENTATION.html in your browser for the separate explanation.
6. In MATLAB, open and run plotResponse.m to plot the supplied verified output.
   To plot your own run, paste the console's Y = [ ... ]; into MATLAB,
   then enter figure(1); plot(Y);

REQUIRED HAND-IN
PID_Controller.hpp and PID_Controller.cpp; show the MATLAB plot.
All six provided C++ files are copied byte-for-byte, including controllerMain.cpp.
Only PID_Controller.hpp and PID_Controller.cpp contain new C++ code.

TO RUN PID
The provided main leaves PID selected code commented out. When you want to run
PID, uncomment the two existing lines below in controllerMain.cpp:
    PID_Controller pidController(0.5, 25, 2.5);
    controller = &pidController;
They occur after the proportional setup, so the later pointer assignment selects
PID. The ZIP leaves both lines commented exactly as supplied.

This project does not pin v143. It lets Visual Studio choose its default toolset.
If Visual Studio still asks for retargeting, choose an installed toolset and SDK.
A plain console project also works: add the four .cpp and four .hpp files here,
and disable precompiled headers. Do not add a second main().
