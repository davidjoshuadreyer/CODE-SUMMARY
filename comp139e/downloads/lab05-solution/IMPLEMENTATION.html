Lab 5 · PID controller

Calculate the next plant input from the target, current plant output, and remembered values from the last call.

Run it

  1. Extract the ZIP and open Lab05.sln in Visual Studio.
  2. Press Ctrl+F5. The one project runs the PID controller for 50 steps.
  3. In MATLAB, open and run plotResponse.m to produce the plot.

To use fresh console output, paste the complete Y = [ ... ]; block into MATLAB, then run figure(1); plot(Y);.

main()
  Controller* → PID_Controller object
  controller calculates input → plant calculates output → repeat

The loop calls controller->controlStep(...) through a base pointer. Because the function is virtual, it runs the PID version. The PID object is local to main(); the pointer does not need delete.

State stored in PID_Controller

MemberMeaningInitial value
kcProportional gain0.5
tIIntegration time constant25
tDDerivative time constant2.5
qLeaky integral of error0
previousOutputPlant output from the previous call0 (plant starts at rest)

q and previousOutput are members so their values survive between calls. The constructor assumes the supplied valid settings; tI must be greater than zero because it is used as a divisor.

One controlStep(), in order

  1. Error: subtract the plant output from the setpoint.
  2. Leaky integral: keep 90% of the old q and add 10% of the current error.
  3. New plant input: apply the exact equation below.
  4. Remember: save the current output for the next call, then return the input.
error = setpoint - plantOutput;
q = 0.9 * q + 0.1 * error;
plantInput = setpoint + kc * (error + (deltaT / tI) * q
    - (tD / deltaT) * (plantOutput - previousOutput));
previousOutput = plantOutput;

The derivative uses the change in plant output, with a minus sign. The integral uses the updated q, not a running sum. Update previousOutput only after calculating the input.

First call: output is 0 and setpoint is 1. Error is 1, q becomes 0.1, and the returned input is 1.502.
