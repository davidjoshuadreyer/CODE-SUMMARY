Probability Rules Sets 1–4 · sample spaces, events, set operations

Look for: "find P(A)", "what is the probability that…", "P(A and B)", "P(A or B)", "A or B but not both", "mutually exclusive", "complement"
Complement: $P(A') = 1 - P(A)$
Addition: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
Mutually exclusive ($A \cap B = \emptyset$): $P(A \cup B) = P(A) + P(B)$
Multiplication: $P(A \cap B) = P(A|B)\cdot P(B) = P(B|A)\cdot P(A)$
Independent ($A \perp B$): $P(A \cap B) = P(A)\cdot P(B)$  and  $P(A|B) = P(A)$
"P(defective) = 0.03, P(defective AND returned) = 0.01 → P(returned | defective) = 0.01/0.03 = 0.333"
"A card is drawn. A=heart, B=face card. P(A∩B)=3/52. P(A|B)=3/12=0.25=P(A)=13/52=0.25 → independent"

Conditional Probability & Bayes' Theorem Sets 5–7

Look for: "given that…", "knowing that…", "P(B|A)", "prior probability", "what fraction of defectives came from machine X?", tree diagram problems
$P(A|B) = \dfrac{P(A \cap B)}{P(B)}$ Conditional probability
Total probability: $P(A) = \sum_i P(A|B_i)\,P(B_i)$ partition $B_1,\ldots,B_k$
Bayes: $P(B_k | A) = \dfrac{P(A|B_k)\,P(B_k)}{\displaystyle\sum_i P(A|B_i)\,P(B_i)}$
"3 machines B₁,B₂,B₃ make 30%/45%/25% of product; defect rates 2%/3%/2%. Given defective, P(B₃)?" → Bayes

Discrete RV
Sets 8–10		 Table of $x$ values & probabilities $f(x)$; "find E(X)", "find V(X)", CDF $F(x) = P(X \le x) = \sum_{t \le x} f(t)$ $E(X^2) = \sum x^2 f(x)$ Linear: $E(aX+b)=a\mu+b$ · $V(aX+b)=a^2\sigma^2$ $\mu = \sum x\,f(x)$
$\sigma^2 = E(X^2) - \mu^2$		 No standardization — use table directly
$X \sim B(n,p)$
Binomial · Set 11		 $n$ fixed trials; P(success) $= p$; independent; $X$ = # successes; two outcomes $b(x;\,n,p) = \dbinom{n}{x} p^x (1-p)^{n-x}$ $\mu = np$
$\sigma^2 = npq$
$q = 1-p$		 If $np \ge 5$ & $nq \ge 5$:
$Z = \dfrac{x - np}{\sqrt{npq}} \sim N(0,1)$
Poisson approx: if $n\ge100$, $np\le10$ → $\lambda=np$
$X \sim \text{Pois}(\lambda)$
Poisson · Set 12		 Events per time/area; avg rate $\lambda$; rare events; no fixed $n$ $p(x;\,\lambda) = \dfrac{e^{-\lambda}\lambda^x}{x!}$, $x = 0,1,2,\ldots$
Scale: rate $r$/unit over $t$ units → $\lambda = r \cdot t$		 $\mu = \lambda$
$\sigma^2 = \lambda$		 "5 calls/hr, 2 hrs" → $\lambda=10$
"2 errors/page, next page" → $e^{-2}$
$X \sim U(A,B)$
Uniform · Sets 13–14		 Equally likely over interval $[A,B]$ $f(x) = \dfrac{1}{B-A}$, $A \le x \le B$
$P(a \le X \le b) = \dfrac{b-a}{B-A}$
$F(x) = \dfrac{x-A}{B-A}$, median: $F(m)=0.5$		 $\mu = \dfrac{A+B}{2}$
$\sigma^2 = \dfrac{(B-A)^2}{12}$		 "U(7,10). P(≤8.8)?" → $(8.8-7)/3 = 0.60$
$X \sim N(\mu,\sigma^2)$
Normal · Sets 15–17		 Bell-shaped, symmetric; mean=median=mode; use z-table for probabilities $P(a < X < b) = \Phi\!\left(\tfrac{b-\mu}{\sigma}\right) - \Phi\!\left(\tfrac{a-\mu}{\sigma}\right)$ $P(Z>z) = 1-\Phi(z)$ · $P(Z<-z) = 1-\Phi(z)$ Percentile: look up $z$ in table body → $x = \mu + z\sigma$ $E(X) = \mu$
$V(X) = \sigma^2$		 $Z = \dfrac{X - \mu}{\sigma} \sim N(0,1)$
Table gives $\Phi(z) = P(Z \le z)$ (left-tail area)
$X \sim \text{Exp}(\lambda)$
Exponential · Set 18		 Time between events / waiting time / component life; memoryless property $f(x) = \lambda e^{-\lambda x}$, $x \ge 0$
$P(X \le x) = 1-e^{-\lambda x}$ · $P(X > x) = e^{-\lambda x}$		 $\mu = 1/\lambda$
$\sigma^2 = 1/\lambda^2$		 Memoryless:
$P(X{>}s{+}t \mid X{>}s) = P(X{>}t)$
"Mean life=15d" → $\lambda=1/15$
Sample Mean $\bar{X}$
CLT · Sets 19–20		 i.i.d. sample size $n$; normal pop → any $n$; any pop → $n \ge 30$ $Z = \dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$
Sample size for CI: $n = \left(\dfrac{z_{\alpha/2}\,\sigma}{E}\right)^2$		 $E(\bar{X}) = \mu$
$\text{SE}(\bar{X}) = \sigma/\sqrt{n}$
$V(\bar{X}) = \sigma^2/n$		 $\bar{X} \sim N\!\left(\mu,\,\sigma^2/n\right)$
CLT applies when $n \ge 30$
Sample Prop. $\hat{p}$
CLT · Set 21		 $np \ge 5$ & $nq \ge 5$ required for normal approx; $\hat{p} = x/n$ $Z = \dfrac{\hat{p} - p}{\sqrt{pq/n}} \sim N(0,1)$
Sample size: $n = z^2_{\alpha/2}/(4E^2)$ if $p$ unknown		 $E(\hat{p}) = p$
$\text{SE}(\hat{p}) = \sqrt{pq/n}$
$V(\hat{p}) = pq/n$		 $\hat{p} \sim N\!\left(p,\,pq/n\right)$
$q = 1-p$

Single Mean Set 22 · one sample, testing/estimating μ

Look for: "mean/average of one group", "Is μ greater/less than X?", "estimate the mean", "one sample"
Case I — σ known (any n)
$Z = \dfrac{\bar{x} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$  ·  CI: $\bar{x} \pm z_{\alpha/2} \cdot \dfrac{\sigma}{\sqrt{n}}$
Case II — σ unknown, n ≥ 30
$Z = \dfrac{\bar{x} - \mu}{s/\sqrt{n}} \sim N(0,1)$  ·  CI: $\bar{x} \pm z_{\alpha/2} \cdot \dfrac{s}{\sqrt{n}}$
Case III — σ unknown, n < 30, normal pop.
$T = \dfrac{\bar{x} - \mu}{s/\sqrt{n}} \sim t_{n-1}$  ·  df $= n-1$  ·  CI: $\bar{x} \pm t_{\alpha/2,\,n-1} \cdot \dfrac{s}{\sqrt{n}}$

Single Proportion Set 23 · $\hat{p} = x/n$

Look for: "proportion/% who…", yes/no outcome, one group, "is the rate greater than p₀?"
"200 voters; 54% support bill. Evidence >50%?" → p₀=0.5, one-tail  |  "80 items, 12 defective. 90% CI for defect rate." → CI, use p̂
$Z = \dfrac{\hat{p} - p_0}{\sqrt{p_0 q_0/n}} \sim N(0,1)$ test → use $p_0$
CI: $\hat{p} \pm z_{\alpha/2}\sqrt{\dfrac{\hat{p}\,\hat{q}}{n}}$ CI → use $\hat{p}$
$n = \dfrac{z^2_{\alpha/2}\,\hat{p}\,\hat{q}}{E^2}$ [$\hat{p}=0.5$ if unknown; $n = z^2/(4E^2)$]

Paired Data Set 26 · same subjects, two conditions

Look for: "before & after", "same subjects measured twice", "matched pairs", "each unit got both treatments"
1. $D_i = X_i - Y_i$  ·  2. find $\bar{d}$ and $s_D$ (1-var stats on D values)
$(\mu_D)_0 = 0$ usually. Non-zero only if claim says "differs by k".
Case I — n ≥ 30
$Z = \dfrac{\bar{d} - (\mu_D)_0}{s_D / \sqrt{n}} \sim N(0,1)$  ·  CI: $\bar{d} \pm z_{\alpha/2} \cdot \dfrac{s_D}{\sqrt{n}}$
Case II — n < 30, differences normal
$T = \dfrac{\bar{d} - (\mu_D)_0}{s_D / \sqrt{n}} \sim t_{n-1}$  ·  CI: $\bar{d} \pm t_{\alpha/2,\,n-1} \cdot \dfrac{s_D}{\sqrt{n}}$

Two Proportions Set 27

Look for: "compare proportions of two groups", two yes/no outcomes, "difference in rates between A and B"
"Men: 24/80 smoke. Women: 18/100 smoke. Higher rate for men?" → test (pool p̂p)  |  "95% CI for difference" → no pool
$\hat{p}_p = (x_1+x_2)/(n_1+n_2)$ pool for test only
$Z = \dfrac{\hat{p}_1-\hat{p}_2}{\sqrt{\hat{p}_p\hat{q}_p\!\left(\tfrac{1}{n_1}+\tfrac{1}{n_2}\right)}} \sim N(0,1)$
CI: $(\hat{p}_1-\hat{p}_2)\pm z_{\alpha/2}\!\sqrt{\dfrac{\hat{p}_1\hat{q}_1}{n_1}+\dfrac{\hat{p}_2\hat{q}_2}{n_2}}$

Two Independent Means Sets 24–25 · two separate groups, compare μ₁ and μ₂

Look for: "compare means of two separate/independent groups", "do A and B differ in average?" — not the same people measured twice (that's paired)
Choose case: σ₁,σ₂ given → I  |  n₁≥30 & n₂≥30 → II  |  small n, $\max(s)/\min(s) \le 1.4$ → III (pooled)  |  ratio > 1.4 → IV (unpooled)
Case I — σ₁, σ₂ known (any n)
$Z = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}} \sim N(0,1)$  ·  CI: $(\bar{x}-\bar{y}) \pm z_{\alpha/2}\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}$
Case II — σ unknown, n₁≥30 & n₂≥30
$Z = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}} \sim N(0,1)$  ·  CI: $(\bar{x}-\bar{y}) \pm z_{\alpha/2}\sqrt{s_1^2/n_1+s_2^2/n_2}$
Case III — small n, ratio ≤ 1.4 (Pooled T)
$s_p^2 = \dfrac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}$  ·  df $= n_1+n_2-2$
$T = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{s_p^2(1/n_1+1/n_2)}} \sim t_{n_1+n_2-2}$
CI: $(\bar{x}-\bar{y}) \pm t_{\alpha/2,\,\nu}\sqrt{s_p^2(1/n_1+1/n_2)}$
Case IV — small n, ratio > 1.4 (Unpooled/Welch T)
$T = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}} \sim t_{\nu}$
$\nu = \left\lfloor\dfrac{(s_1^2/n_1+s_2^2/n_2)^2}{\tfrac{(s_1^2/n_1)^2}{n_1-1}+\tfrac{(s_2^2/n_2)^2}{n_2-1}}\right\rfloor$
CI: $(\bar{x}-\bar{y}) \pm t_{\alpha/2,\,\nu}\sqrt{s_1^2/n_1+s_2^2/n_2}$

Chi-Square Tests Sets 31–32 · $\chi^2 = \sum(O-E)^2/E$

Look for: "does the data follow distribution X?" (GOF)  |  "are two categorical variables independent/related?" (independence)  |  observed vs expected counts in a table
"A die rolled 180 times — is it balanced?" → GOF, k=6 categories, E=30 each  |  "TV hours vs gender — are they independent?" → contingency table test
Goodness-of-Fit (GOF) — Set 31
H₀: data follows the specified distribution
$E_i = n \cdot p_i$   (expected count for category $i$)
$\chi^2 = \sum_{i=1}^{k} \dfrac{(O_i - E_i)^2}{E_i} \sim \chi^2_{k-1}$
df $= k - 1$   ($k$ = number of categories)
Reject H₀ if $\chi^2_\text{obs} > \chi^2_{\alpha,\,k-1}$ (upper tail only)
Test of Independence — Set 32
H₀: the two categorical variables are independent
$E_{ij} = \dfrac{(\text{row}_i \text{ total})\times(\text{col}_j \text{ total})}{n}$
$\chi^2 = \sum_{i,j} \dfrac{(O_{ij} - E_{ij})^2}{E_{ij}} \sim \chi^2_{(r-1)(c-1)}$
df $= (r-1)(c-1)$  ($r$ rows, $c$ columns)
Reject H₀ if $\chi^2_\text{obs} > \chi^2_{\alpha,\,(r-1)(c-1)}$

Regression & Correlation Sets 28–30 · $\hat{y} = b_0 + b_1 x$ · always compute $s_{xy}$, $s_x^2$, $s_y^2$ first

Look for: "predict Y from X", "linear relationship", "for each unit increase in X, Y changes by…", "correlation", "fit a line to the data"
Variables: x = predictor (independent/explanatory)  ·  y = response (dependent/outcome)  ·  ŷ = predicted value of y  ·  b₀ = y-intercept (value of y when x=0)  ·  b₁ = slope (change in y for each +1 unit of x)  ·  β₁ = true (population) slope  ·  e = y−ŷ = residual (actual minus predicted, positive = above line)
sxy = sample covariance of x & y  ·  sx², sy² = sample variances of x and y  ·  r = sample correlation coefficient (−1 ≤ r ≤ 1; sign = direction, magnitude = strength)  ·  ρ = true (population) correlation  ·  R² = coefficient of determination = % of variation in y explained by x  ·  SSE = sum of squared residuals  ·  sε = standard error of regression (typical distance of points from the line)
Step 1 — Compute summary statistics
$s_{xy} = \dfrac{\displaystyle\sum x_i y_i - \dfrac{(\sum x_i)(\sum y_i)}{n}}{n-1}$
$s_x^2 = \dfrac{\sum x_i^2 - (\sum x_i)^2/n}{n-1}$   (same form for $s_y^2$)
Compute $\sum x_iy_i$ by hand (multiply pairs, sum up)
Step 2 — Regression line
$b_1 = s_{xy}/s_x^2$  ·  $b_0 = \bar{y} - b_1\bar{x}$
$\hat{y} = b_0 + b_1 x$  ·  residual: $e = y - \hat{y}$
Step 3 — Correlation & fit
$r = s_{xy}/(s_x \cdot s_y)$  ·  $R^2 = r^2$
$\text{SSE} = (n-1)\!\left(s_y^2 - s_{xy}^2/s_x^2\right)$  ·  $s_\varepsilon = \sqrt{\text{SSE}/(n-2)}$
Step 4 — Hypothesis tests (both use $t_{n-2}$)
$s_{b_1} = \dfrac{s_\varepsilon}{\sqrt{(n-1)s_x^2}}$ e.s.e. of slope $b_1$
Test slope: $T = b_1/s_{b_1} \sim t_{n-2}$  ·  $H_0\!:\beta_1=0$ (no relationship)
Test corr: $T = r\sqrt{(n-2)/(1-r^2)} \sim t_{n-2}$  ·  $H_0\!:\rho=0$
Both tests are equivalent — same t_obs and same p-value.
z critical values
Two-tail: 90%→1.645 · 95%→1.96 · 99%→2.576
One-tail:  90%→1.28  · 95%→1.645 · 99%→2.33
Other: 94%→1.88 · 98%→2.326 · 99.5%→2.807
p-value from z-table (table gives $P(Z < z)$):
$H_1\!:\theta > $ val → p $= 1 - \Phi(z_\text{obs})$  upper tail
$H_1\!:\theta < $ val → p $= \Phi(z_\text{obs})$  lower tail
$H_1\!:\theta \neq$ val → p $= 2(1 - \Phi(|z_\text{obs}|))$  two-tail
Bracket p-value from t-table (same tail rules):
$t_\text{obs}=2.49$, df$=11$, one-tail:
$t_{0.025,11}=2.201 < 2.49 < t_{0.01,11}=2.718$
→ $0.01 < $ p $< 0.025$
Two-tail: double the bracket.
Key traps:
Prop CI → use $\hat{p}$;  test → use $p_0$
2-prop test → pool $\hat{p}_p$;  CI → no pool
$(\mu_1-\mu_2)_0=0$ unless claim says "by $k$"
Before/after same subject → paired, not 2-sample
$\chi^2$ always upper tail only
