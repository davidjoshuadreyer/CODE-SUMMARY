Single Mean Set 22 · one sample, σ unknown

Look for: "mean/average", "one group/sample", "Is the mean greater/less than X?", "estimate the mean μ"
"σ=1.4 is known for this process…" → Case I  |  "Survey of 50 households, s=$85" → n≥30, σ unknown → Case II  |  "Sample of 10 patients, s=1.4" → n<30 → Case III
Case I — σ known (any n)
$Z = \dfrac{\bar{x} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$  ·  CI: $\bar{x} \pm z_{\alpha/2} \cdot \dfrac{\sigma}{\sqrt{n}}$
Case II — σ unknown, n ≥ 30
$Z = \dfrac{\bar{x} - \mu}{s/\sqrt{n}} \sim N(0,1)$  ·  CI: $\bar{x} \pm z_{\alpha/2} \cdot \dfrac{s}{\sqrt{n}}$
Case III — σ unknown, n < 30, normal population
$T = \dfrac{\bar{x} - \mu}{s/\sqrt{n}} \sim t_{n-1}$  ·  df $= n-1$  ·  CI: $\bar{x} \pm t_{\alpha/2,\,n-1} \cdot \dfrac{s}{\sqrt{n}}$

Single Proportion Set 23

$\hat{p} = x/n$ · e.s.e.(CI) $= \sqrt{\hat{p}(1-\hat{p})/n}$
Look for: "proportion/% who...", "more than half...", yes/no outcome, one group, "is the rate greater than p₀?"
"200 voters; 54% support bill. Evidence >50% support?" → p₀=0.5, one-tail test  |  "80 items, 12 defective. Estimate true defect rate with 90% CI." → CI (use p̂, not p₀)
$Z = \dfrac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}} \sim N(0,1)$ test → use $p_0$
CI: $\hat{p} \;\pm\; z_{\alpha/2}\sqrt{\dfrac{\hat{p}(1-\hat{p})}{n}}$
$n = \dfrac{z^2_{\alpha/2}\cdot\hat{p}(1-\hat{p})}{E^2}$ [$\hat{p}=0.5$ if unknown]

Paired Data Set 26 · same subjects, two treatments

Look for: "before & after", "same subjects measured twice", "matched pairs", "each participant received both treatments"
"10 runners timed before and after training. Did training reduce mean time?" → D = before−after  |  "BP measured morning & evening for 8 patients. Is there a difference?" → same person = paired, not 2-sample
1. Compute: $D_i = X_i - Y_i$  (e.g. after – before)
2. Find $\bar{d}$ and $s_D$  ← calculator 1-var stats on the $D_i$ values  ($\bar{x}=\bar{d}$, $s_x = s_D$)
Usually $(\mu_D)_0 = 0$ ("no difference"). Non-zero only if claim says "by k" — e.g. "reduces by 5" → $(\mu_D)_0 = 5$.
Case I — n ≥ 30 (large number of pairs)
3. $Z = \dfrac{\bar{d} - (\mu_D)_0}{s_D / \sqrt{n}} \sim N(0,1)$  ·  CI: $\bar{d} \pm z_{\alpha/2} \cdot \dfrac{s_D}{\sqrt{n}}$
Case II — n < 30, differences are normal
3. $T = \dfrac{\bar{d} - (\mu_D)_0}{s_D / \sqrt{n}} \sim t_{n-1}$  ·  CI: $\bar{d} \pm t_{\alpha/2,\,n-1} \cdot \dfrac{s_D}{\sqrt{n}}$

Two Proportions Set 27

pool $\hat{p}_p$ for test only; unpooled ese for CI
Look for: "compare proportions of two groups", two yes/no outcomes, "difference in rates/percentages between A and B"
"80 men, 24 smoke; 100 women, 18 smoke. Is smoking rate higher for men?" → test (pool p̂p)  |  "Find 95% CI for difference in support rates." → CI (no pooling)
$\hat{p}_p = (x_1+x_2)/(n_1+n_2)$ ← H-test only
$Z = \dfrac{\hat{p}_1-\hat{p}_2}{\sqrt{\hat{p}_p(1-\hat{p}_p)\!\left(\tfrac{1}{n_1}+\tfrac{1}{n_2}\right)}} \sim N(0,1)$
CI: $(\hat{p}_1-\hat{p}_2)\pm z_{\alpha/2}\!\sqrt{\dfrac{\hat{p}_1(1-\hat{p}_1)}{n_1}+\dfrac{\hat{p}_2(1-\hat{p}_2)}{n_2}}$

Two Independent Means Sets 24–25

Look for: "compare means of two separate groups", "do A and B differ in average?", "two independent samples" — not the same people measured twice
σ₁,σ₂ given → Case I  |  n₁=50,n₂=45, σ unknown → Case II  |  small n, s ratio ≤1.4 → Case III  |  s ratio >1.4 → Case IV
Case I — σ₁,σ₂ known (any n)
$Z = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}} \sim N(0,1)$  ·  CI: $(\bar{x}-\bar{y}) \pm z_{\alpha/2}\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}$
Case II — σ unknown, n₁≥30 & n₂≥30
$Z = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}} \sim N(0,1)$  ·  CI: $(\bar{x}-\bar{y}) \pm z_{\alpha/2}\sqrt{s_1^2/n_1+s_2^2/n_2}$
Case III — small n, ratio ≤ 1.4 (equal var, Pooled T)
$s_p^2 = \dfrac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}$
$T = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{s_p^2\!\left(\tfrac{1}{n_1}+\tfrac{1}{n_2}\right)}} \sim t_{n_1+n_2-2}$
CI: $(\bar{x}-\bar{y}) \pm t_{\alpha/2,\nu}\sqrt{s_p^2\!\left(\tfrac{1}{n_1}+\tfrac{1}{n_2}\right)}$
Case IV — small n, ratio > 1.4 (unequal var, Unpooled T)
$T = \dfrac{\bar{x}-\bar{y}-(\mu_1-\mu_2)_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}} \sim t_{\nu}$
$\nu = \left\lfloor\dfrac{(s_1^2/n_1+s_2^2/n_2)^2}{\tfrac{(s_1^2/n_1)^2}{n_1-1}+\tfrac{(s_2^2/n_2)^2}{n_2-1}}\right\rfloor$
CI: $(\bar{x}-\bar{y}) \pm t_{\alpha/2,\nu}\sqrt{s_1^2/n_1+s_2^2/n_2}$

Regression & Correlation Sets 28–30 · $\hat{Y} = b_0 + b_1 x$ · compute $s_{xy}$, $s_x^2$, $s_y^2$ first

Look for: "predict Y from X", "linear relationship between X and Y", "for each unit increase in X, Y changes by...", "correlation"
"Hours studied (x) vs exam score (y). Find regression line; test if x is a significant predictor." · "Interpret b₁: each extra hour → score ↑ by b₁ pts" · "Predict score when x=6."
Variables: x = predictor (independent/explanatory) · y = response (dependent/outcome) · ŷ = predicted y · b₀ = y-intercept (y when x=0) · b₁ = slope (change in y per +1 x) · β₁ = true slope · e = y−ŷ = residual (actual − predicted)
sxy = sample covariance of x & y · sx², sy² = sample variances · r = correlation (−1 ≤ r ≤ 1, strength & direction) · ρ = true correlation · R² = % of variation in y explained by x · SSE = sum of squared residuals · sε = std error of regression (avg distance from line)
$s_{xy} = \dfrac{\displaystyle\sum x_i y_i - \dfrac{(\sum x_i)(\sum y_i)}{n}}{n-1}$ compute $\sum x_i y_i$ by hand
$s_x^2 = \dfrac{\sum x_i^2 - (\sum x_i)^2/n}{n-1}$   same for $s_y^2$
$b_1 = s_{xy}/s_x^2$  ·  $b_0 = \bar{y} - b_1\bar{x}$  ·  residual: $e = y - \hat{y}$
$\text{SSE} = (n-1)\!\left(s_y^2 - \dfrac{s_{xy}^2}{s_x^2}\right)$  ·  $s_\varepsilon = \sqrt{\dfrac{\text{SSE}}{n-2}}$
$r = s_{xy}/(s_x\!\cdot\! s_y)$  ·  $R^2 = r^2$
$s_{b_1} = \dfrac{s_\varepsilon}{\sqrt{(n-1)s_x^2}}$ e.s.e. of $b_1$
T (slope): $T = b_1/s_{b_1} \sim t_{n-2}$ · $H_0\!:\beta_1=0$ vs $H_1\!:\beta_1\neq 0$
T (corr): $T = r\sqrt{(n-2)/(1-r^2)} \sim t_{n-2}$ · $H_0\!:\rho=0$
Critical values (c.v.):
Two-tail: 90%→1.645 · 95%→1.96 · 99%→2.576
One-tail:  90%→1.28  · 95%→1.645 · 99%→2.33
p-value from z-table (table gives $P(Z < z)$):
$H_1\!:\theta >$ val  →  p $= 1 -$ table$(z_\text{obs})$  upper tail
$H_1\!:\theta <$ val  →  p $=$ table$(z_\text{obs})$  lower tail
$H_1\!:\theta \neq$ val  →  p $= 2(1-$ table$(|z_\text{obs}|))$  two-tail
p-value from t-table (same tail rules, bracket $t_\text{obs}$ by df):
e.g. $t_\text{obs}=2.49$, df$=11$:
$t_{0.025,11}=2.201 < 2.49 < t_{0.01,11}=2.718$
→ $0.01 <$ p $< 0.025$ (one-tail)
Traps:
CI prop → $\hat{p}$;  test → $p_0$
2-prop test → pool $\hat{p}_p$;  CI → no pool
$(\mu_1-\mu_2)_0=0$ unless claim says "by $k$"
Before/after → paired, not 2-sample
