Series and parallel resistors

Decide what is shared: current or voltage.

Given: A 12.0 V source drives R₁ = 2.00 Ω and R₂ = 4.00 Ω in series.

Find: The total current and each voltage drop.

Define the variables

R₁, R₂: resistor values (Ω); Rₑq: equivalent resistance (Ω); I: common series current (A); V₁, V₂: resistor voltage drops (V); Vₛ: source voltage (V).

Worked example

  1. Recognize series

    There is only one current path and no branch between the resistors. Both carry the same current.

  2. Combine resistances

    Req=R1+R2=6.00 Ω,I=VsReq=2.00 AR_{eq}=R_1+R_2=6.00\ \Omega,\qquad I=\frac{V_s}{R_{eq}}=2.00\ \mathrm AReq​=R1​+R2​=6.00 Ω,I=Req​Vs​​=2.00 A

  3. Find each drop

    V1=IR1=4.00 V,V2=IR2=8.00 VV_1=IR_1=4.00\ \mathrm V,\qquad V_2=IR_2=8.00\ \mathrm VV1​=IR1​=4.00 V,V2​=IR2​=8.00 V

  4. Check the loop

    The drops sum to the source voltage: 4.00 + 8.00 = 12.0 V.
Check your answer

For parallel resistors, voltage is shared and 1/Rₑq = 1/R₁ + 1/R₂. Do not add parallel resistances directly.

Try it yourself

Instead connect the same two resistors in parallel across 12.0 V. Find total current.

Show the worked answer

Each branch sees 12.0 V. I₁ = 12/2 = 6.00 A, I₂ = 12/4 = 3.00 A, so the source supplies 9.00 A. Rₑq = 12/9 = 1.33 Ω.
