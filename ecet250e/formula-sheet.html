ECET midterm · Basic calculations · 1/3

01 / Electrons, charge vs. time, or a current graph.

Find charge or current

  1. Electrons: multiply the number of electrons by their signed charge.
  2. Given charge q(t): differentiate to find current.
  3. Given current: integrate, or find the signed area under the graph. Add any initial charge.
Q=−Ne,e=1.602×10−19 CQ=-Ne,\quad e=1.602\times10^{-19}\,\mathrm CQ=−Ne,e=1.602×10−19Ci=dqdt,Δq=∫i dti=\frac{dq}{dt},\qquad \Delta q=\int i\,dti=dtdq​,Δq=∫idt

Constant current: Δq = IΔt. Below the time axis means negative area.

02 / Find equivalent resistance or total current.

Simplify a resistor network

  1. Mark the nodes. Series means the same current with no branch between; parallel means both ends share the same two nodes.
  2. Replace one series or parallel group at a time. Redraw and repeat.
  3. Use Ohm’s law on the reduced circuit; work backwards for individual values.
Rs=R1+R2+⋯R_s=R_1+R_2+\cdotsRs​=R1​+R2​+⋯Rp=R1R2R1+R2 (two),1Rp=∑1RkR_p=\frac{R_1R_2}{R_1+R_2}\ \text{(two)},\qquad \frac1{R_p}=\sum\frac1{R_k}Rp​=R1​+R2​R1​R2​​ (two),Rp​1​=∑Rk​1​V=IRV=IRV=IR

Parallel resistance must be smaller than the smallest branch. No reducible groups? Use nodal or mesh.

03 / Find one resistor’s voltage or one parallel branch’s current.

Split voltage or current

  1. Series chain: find its total voltage and total resistance, then use voltage division.
  2. Two parallel branches: find the total current entering the pair, then use current division.
  3. Include the load first. For more parallel branches, find their common voltage, then use I = V/R.
Vx=VtotalRxRtotalV_x=V_{\mathrm{total}}\frac{R_x}{R_{\mathrm{total}}}Vx​=Vtotal​Rtotal​Rx​​I1=ItotalR2R1+R2I_1=I_{\mathrm{total}}\frac{R_2}{R_1+R_2}I1​=Itotal​R1​+R2​R2​​

Current division uses the OTHER resistor in the numerator. The lower resistance carries more current.

04 / Absorbed / delivered power, resistor heating, or energy over time.

Find power or energy

  1. Mark voltage polarity and current direction.
  2. Current entering +: use p = vi. Current entering −: use p = −vi.
  3. Positive power is absorbed; negative power is delivered. For energy, integrate power over time.
PR=I2R=V2RP_R=I^2R=\frac{V^2}{R}PR​=I2R=RV2​Δw=∫p dt(constant power: Δw=PΔt)\Delta w=\int p\,dt\quad\text{(constant power: }\Delta w=P\Delta t\text{)}Δw=∫pdt(constant power: Δw=PΔt)

Check: signed powers sum to zero. Resistors always absorb power.

ECET midterm · Circuit-solving methods · 2/3

05 / Several branches meet; current sources; asked for a node voltage.

Nodal analysis → node voltages

  1. Choose ground (0 V). Label each remaining node voltage.
  2. At each unknown node, write currents leaving through resistors as (this node − other node)/R. Set their sum equal to net source current entering.
  3. Voltage source to ground: that node voltage is known. Between two unknown nodes: enclose both as a supernode, write KCL around it, and add V+ − V− = Vs.
  4. Solve the simultaneous equations. Find the requested branch current using its voltage difference / R.
Ia→b=Va−VbRI_{a\to b}=\frac{V_a-V_b}{R}Ia→b​=RVa​−Vb​​

Keep dependent sources active and add their control equation. Negative current means opposite your chosen arrow.

06 / A planar circuit with a few loops; voltage sources; asked for current.

Mesh analysis → loop currents

  1. Draw one clockwise current in each small loop.
  2. Write KVL: total resistor drops = signed source rises. A shared resistor’s drop in mesh 1 is R(I₁ − I₂).
  3. Current source on one mesh’s outer edge: it fixes that mesh current (check arrow). Shared current source: write KVL around both meshes as a supermesh, then add the current-source constraint.
  4. Solve the equations. A shared branch carries the difference of its mesh currents.
VR,shared=R(I1−I2)V_{R,\mathrm{shared}}=R(I_1-I_2)VR,shared​=R(I1​−I2​)

Crossing a voltage source from − to + is a rise. Retain dependent-source control equations.

07 / Asked to use superposition, or to find each source’s contribution.

Superposition → one source at a time

  1. Keep one independent source on. Turn off the other independent sources: voltage source → short; current source → open.
  2. Keep ALL dependent sources on. Solve for the requested voltage or current using the same reference direction every time.
  3. Repeat for each independent source. Add the signed contributions.
  4. If asked for power, calculate it from the final total voltage/current.

Never add individual source contributions to power; power does not superpose.

08 / A voltage source with series R, or a current source with parallel R.

Source transformation → easier circuit

  1. Voltage source + series R ↔ current source + parallel R. Keep the same resistance and the same two external terminals.
  2. Use Is = Vs/R or Vs = IsR. The current-source arrow points toward the voltage source’s + terminal.
  3. Redraw, simplify, and repeat if useful.
Is=VsR⟷Vs=IsRI_s=\frac{V_s}{R}\qquad\longleftrightarrow\qquad V_s=I_sRIs​=RVs​​⟷Vs​=Is​R

The resistor must actually be in series / parallel with that source. The equivalent preserves terminal behaviour.

Before calculating: convert units. k = 10³ · m = 10⁻³ · μ = 10⁻⁶ · n = 10⁻⁹ · p = 10⁻¹². Graph: slope = Δy/Δt; triangle area = ½ × base × height. Keep signs.

ECET midterm · Equivalent circuits & energy storage · 3/3

09 / Find an equivalent at a–b, or the current through a load.

Thévenin / Norton → replace a network

  1. Remove the load RL. Find the open-terminal voltage: VTh = Vab.
  2. Find RTh looking into a–b: short independent voltage sources and open independent current sources. Combine the resistors.
  3. If dependent sources remain: keep them active, apply a test voltage at a–b, find current entering its + terminal, and use RTh = Vtest/Itest.
  4. Reconnect RL to VTh in series with RTh. For Norton, use IN = VTh/RTh in parallel with the same RTh.
IL=VThRTh+RLI_L=\frac{V_{\mathrm{Th}}}{R_{\mathrm{Th}}+R_L}IL​=RTh​+RL​VTh​​

Norton alternative: IN is the short-circuit current from a to b. Its source arrow points toward terminal a when VTh = Va − Vb.

10 / Find RL for maximum power, then find that power.

Choose a load for maximum power

  1. Remove the load. Find VTh and RTh using the method above.
  2. For an adjustable resistive load and positive RTh, set RL = RTh.
  3. Use the maximum-power formula. If RL is fixed, use the ordinary load-current formula and PL = IL²RL instead.
RL=RTh,Pmax⁡=VTh24RThR_L=R_{\mathrm{Th}},\qquad P_{\max}=\frac{V_{\mathrm{Th}}^2}{4R_{\mathrm{Th}}}RL​=RTh​,Pmax​=4RTh​VTh2​​

Match the resistance seen by the load, not one resistor picked from the original circuit.

11 / Given v(t), find i(t); given i(t), find v(t); find charge or energy.

Capacitor → slope, area, stored energy

  1. Given voltage: differentiate it (graph → slope), then multiply by C.
  2. Given current: take signed area / C, then add the initial voltage.
  3. Combine capacitors: parallel values add; series uses reciprocals (two in series: C₁C₂/(C₁+C₂)).
i=Cdvdt,v=v0+1C∫t0ti dti=C\frac{dv}{dt},\qquad v=v_0+\frac1C\int_{t_0}^{t}i\,dti=Cdtdv​,v=v0​+C1​∫t0​t​idtq=Cv,w=12Cv2q=Cv,\qquad w=\tfrac12Cv^2q=Cv,w=21​Cv2

At DC steady state: open circuit. Voltage cannot jump for finite current. Use current entering the + voltage terminal.

12 / Given i(t), find v(t); given v(t), find i(t); find energy.

Inductor → slope, area, stored energy

  1. Given current: differentiate it (graph → slope), then multiply by L.
  2. Given voltage: take signed area / L, then add the initial current.
  3. Uncoupled inductors combine like resistors: series values add; parallel uses reciprocals.
v=Ldidt,i=i0+1L∫t0tv dtv=L\frac{di}{dt},\qquad i=i_0+\frac1L\int_{t_0}^{t}v\,dtv=Ldtdi​,i=i0​+L1​∫t0​t​vdtw=12Li2w=\tfrac12Li^2w=21​Li2

At DC steady state: short circuit. Current cannot jump for finite voltage. Use current entering the + voltage terminal.
