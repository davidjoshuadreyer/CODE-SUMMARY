Nodal analysis, step by step

Use current balance to find an unknown voltage.

Given: Node v connects to a 12.0 V node through R₁ = 2.00 kΩ and to ground through R₂ = 4.00 kΩ. No other branch is connected.

Find: The node voltage v and both resistor currents.

Define the variables

v: unknown node voltage relative to ground (V); ground: the 0 V reference; R₁, R₂: resistances (Ω); I₁: current from the 12 V node into v; I₂: current from v to ground (A).

Worked example

  1. Choose ground

    Set the lower reference node to 0 V. Mark the unknown junction voltage v.

  2. Write branch currents

    I1=12−v2000,I2=v4000I_1=\frac{12-v}{2000},\qquad I_2=\frac{v}{4000}I1​=200012−v​,I2​=4000v​

  3. Apply current balance

    I1=I2⇒12−v2000=v4000I_1=I_2\quad\Rightarrow\quad\frac{12-v}{2000}=\frac{v}{4000}I1​=I2​⇒200012−v​=4000v​

  4. Solve and check

    2(12−v)=v⇒v=8.00 V2(12-v)=v\quad\Rightarrow\quad v=8.00\ \mathrm V2(12−v)=v⇒v=8.00 VI1=I2=2.00 mAI_1=I_2=2.00\ \mathrm{mA}I1​=I2​=2.00 mACurrent entering the node equals current leaving it.
Check your answer

The answer lies between 0 V and 12 V. A negative branch current would mean the true direction is opposite to the one you chose.

Try it yourself

Replace R₂ with 2.00 kΩ. What is v?

Show the worked answer

(12 − v)/2000 = v/2000, so 12 − v = v and v = 6.00 V. Each branch current is 3.00 mA.
